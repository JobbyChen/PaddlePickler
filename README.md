# 🏓 PaddlePicker — Personalized Pickleball Paddle Recommender

An interactive pickleball paddle recommendation application built with **Python and Streamlit** that helps players find paddles based on their skill level, playing style, budget, and performance preferences.

**[🚀 Try PaddlePicker Live](https://paddlepickler-qpxpywmjzpoftum8gcmuli.streamlit.app/)**

## Project Overview

Choosing the right pickleball paddle can be challenging due to differences in price, weight, handle length, thickness, and performance characteristics.

PaddlePicker simplifies this process by analyzing user preferences and ranking paddles using a custom weighted scoring algorithm.

The application combines structured product data, filtering logic, and personalized recommendations to help users make informed purchasing decisions.

## Key Features

- **Personalized Recommendations:** Ranks paddles based on individual preferences.
- **Weighted Scoring Algorithm:** Evaluates power, control, spin, forgiveness, skill compatibility, and playing style.
- **Budget-Aware Ranking:** Adjusts scores based on budget preferences and price constraints.
- **Advanced Filtering:** Filters by handle category, weight category, price category, and playing style.
- **Interactive Interface:** Uses sliders, dropdown menus, and selection controls.
- **Explainable Recommendations:** Generates explanations describing why each paddle matches the user's preferences.
- **Product Comparisons:** Displays pricing, weight, handle length, thickness, and performance ratings.
- **Product Images and Links:** Supports product imagery and external product links when available.
